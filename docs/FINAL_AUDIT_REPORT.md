## 3. Известные баги / ограничения / предложения

### 3.1. Критично перед production

| # | Проблема | Приоритет | Предложение |
|---|---|---|---|
| 1 | **Vercel SSO** | Высокий | Production-деплой на Vercel защищён и требует авторизации. Перед выпуском в открытый доступ обсудить отключение защиты или альтернативный хостинг. |
| 2 | **Малое наполнение каталога** | Высокий | Сейчас 11 товаров в 7 категориях. Для production нужно реальное наполнение: описания, характеристики, изображения, цены, остатки. |
| 3 | **Checkout — UI-макет без платежей** | Высокий | Форма оформления заказа не интегрирована с платёжным провайдером и службой доставки. Нужна интеграция (например, Stripe / YooKassa / Беларусь-банк) и расчёт доставки. |

### 3.2. Средний приоритет

| # | Проблема | Предложение |
|---|---|---|
| 4 | **Performance mobile — 0.44** | LCP главной страницы связан с видео/изображениями. Предложения: lazy-load видео, преобразовать hero-видео в WebM/MP4 с меньшим битрейтом, использовать `loading="eager"` только для LCP-изображения, рассмотреть отложенную загрузку нижних блоков. |
| 5 | **Отсутствие настояего бэкенда** | Все товары, новости, отзывы — статические данные. Для production нужна CMS, админка или хотя бы JSON API с возможностью обновления без пересборки. |
| 6 | **SEO-страницы категорий** | Страницы категорий имеют только `<title>`. Добавить `<meta name="description">`, OpenGraph, canonical, хлебные крошки. |
| 7 | **Страница товара (PDP)** | Нет отзывов на странице, нет похожих товаров, нет развёрнутых характеристик/таблиц. Добавить. |
| 8 | **Wishlist на мобильной версии** | Кнопка избранного в карточке теперь всегда видна, но wishlist-страница не оптимизирована под мобильную ширину — проверить отступы и кнопки. |

### 3.3. Низкий приоритет / полировка

| # | Проблема | Предложение |
|---|---|---|
| 9 | **Hero-слайдер: свайп на мобиле** | Playwright-свайп не сменил слайд, хотя автоперелистывание работает. Проверить вручную на реальном устройстве; при необходимости добавить `onPointerDown`/`onTouchStart` обработчики для свайпа. |
| 10 | **Контраст и цвета** | Accessibility desktop 0.93 — проверить, какой именно элемент снижает оценку, и довести до 1. |
| 11 | **Формы: валидация и UX** | Добавить inline-валидацию, маски телефона, сообщения об ошибках, состояние disabled при отправке. |
| 12 | **404-страница** | Создать кастомную `src/app/not-found.tsx` в стиле сайта. |
| 13 | **Sitemap / robots.txt** | Для SEO добавить динамический `sitemap.xml` и `robots.txt`. |
| 14 | **Аналитика** | Cookie consent есть, но сама аналитика (GA4 / Яндекс.Метрика) не подключена. Подключить и связать с баннером. |
| 15 | **PWA / manifest** | Можно добавить `manifest.json`, иконки, service worker для базового офлайна. |
| 16 | **Тесты** | Добавить unit-тесты для `formatPrice`, `formatPhone`, `searchProducts`, контекстов корзины/избранного. |
